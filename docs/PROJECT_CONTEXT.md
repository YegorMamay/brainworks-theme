# PROJECT_CONTEXT

## 1. Краткое описание проекта
Минимальная «голая» тема для WordPress (Brainworks). Базовый каркас для дальнейшей разработки без лишней функциональности.

## 2. Цели проекта
- **Основная цель:** рабочая классическая тема WordPress с минимально необходимым набором файлов.
- **Вторичные цели:** поддержка PHP 7.4+, готовность к расширению; возможность перевода через Loco Translate; совместимость с WooCommerce.

## 3. Область ответственности
### Входит в проект
- Шаблоны вывода (header, main, footer), базовая поддержка темы (title-tag, html5, thumbnails, text domain). Поддержка WooCommerce (объявление в теме). Готовность к переводу (text domain brainworks, load_theme_textdomain, папка languages для Loco Translate).

### Не входит в проект
- Плагины (кроме совместимости с WooCommerce и Loco Translate), кастомные типы записей, сложная вёрстка, блоки (FSE) — на текущем этапе.

## 4. Целевая аудитория / пользователь
Разработчики, дорабатывающие тему под конкретный сайт на WordPress.

## 5. Ограничения
- Технические: PHP 7.4 и выше; классическая тема (не block theme).
- Временные: —
- Бизнес: —

## 6. Критерии успеха
- Тема активируется в WordPress без ошибок, отображает записи и страницы, корректно выводит заголовок и подключает стили. С Loco Translate можно переводить строки темы. При установленном WooCommerce магазин отображается без предупреждений о несовместимости темы.

## 7. Текущий статус
- В разработке (минимальный каркас создан).
