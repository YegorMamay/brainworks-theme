# DOCUMENTATION

Руководство по кастомному функционалу темы Brainworks для пользователей и разработчиков, которые разрабатывают сайты на базе этой темы.

---

## 1. Логотипы (Customizer)

В настройках темы можно задать два логотипа.

**Где настраивается:** Внешний вид → Настроить → **Свойства сайта** (Site Identity).

| Поле | Описание |
|------|----------|
| **Main Logo** | Основной логотип. Выводится в шапке сайта (если загружен). Рекомендуется изображение с прозрачным фоном. |
| **Second Logo** | Второй логотип (например, для подвала или светлого варианта). Выводится только через шорткод. |

Если Main Logo не задан, в шапке отображается название сайта (как текст).

---

## 2. Шорткоды логотипов

Логотипы можно выводить в контенте страниц и записей с помощью шорткодов.

### Шорткоды

| Шорткод | Назначение |
|---------|------------|
| **`[main_logo]`** | Вывод основного логотипа (Main Logo). |
| **`[second_logo]`** | Вывод второго логотипа (Second Logo). |

### Атрибуты (общие для обоих)

- **`link="yes"`** (по умолчанию) или **`link="no"`** — оборачивать ли логотип в ссылку на главную страницу.
- **`size="medium"`** (по умолчанию), **`thumbnail`**, **`full`** — размер изображения (размеры WordPress).
- **`class="..."`** — дополнительные CSS-классы для обёртки логотипа.

### Примеры

```
[main_logo]
```

```
[second_logo link="no" size="full"]
```

```
[main_logo class="my-logo" size="thumbnail"]
```

## 3. Телефоны (Phones)

В настройках темы можно задать до 6 номеров телефонов. Для каждого номера доступны: само число, кастомный CSS-класс для ссылки и иконка (изображение), которая выводится перед номером (например, иконка оператора).

**Где настраивается:** Внешний вид → Настроить → **Phones**.

Для каждого из 6 слотов:

| Поле | Описание |
|------|----------|
| **Phone 1 … Phone 6** | Номер. **Поддерживает HTML** (например, `<b>`, `<span>`). Пример: `+38 <b>(063)</b> 20-37-130`. |
| **Phone N — Description** | Текст описания (например, имя менеджера), выводится справа от номера. |
| **Phone N — CSS class for link** | Дополнительный класс для тега `<a>` этого номера (например, для отдельной стилизации). |
| **Phone N — icon (image before number)** | Изображение (иконка), которое выводится перед номером. |

Ссылки выводятся как кликабельные: `tel:+380632037130` (из номера берутся только цифры, перед ними подставляется `+`).

### Шорткод [phones]

Вывод всех заполненных телефонов в выбранном формате.

| Атрибут | Значение | Описание |
|--------|----------|----------|
| **format** | `list` (по умолчанию) | Номера списком `<ul>`. |
| | `column` | Номера в колонку (несколько ссылок подряд). |
| | `dropdown` | Выпадающий список; первый номер виден всегда, остальные появляются по клику. |
| **class** | произвольная строка | Дополнительные CSS-классы для обёртки блока. |
| **dropdown_bg** | любое CSS-значение цвета | Цвет фона выпадающего списка. Удобно для тёмных фонов. |
| **dropdown_color** | любое CSS-значение цвета | Цвет текста/ссылок внутри выпадающего списка. |

> Атрибуты `dropdown_bg` и `dropdown_color` работают для всех форматов (устанавливаются как CSS custom properties на обёртке), но особенно важны для `format="dropdown"`, когда шорткод размещён на тёмном фоне (например, в шапке).

**Примеры:**

```
[phones]
[phones format="column"]
[phones format="dropdown" class="header-phones"]
[phones format="dropdown" dropdown_bg="#1a1a1a" dropdown_color="#ffffff"]
```

Стили телефонов задаются в отдельном файле **assets/scss/shortcodes/_phones.scss** (классы `.phones`, `.phones--list`, `.phones--column`, `.phones--dropdown`, `.phones__link`, `.phones__icon`, `.phones__desc`, `.phones__number` и др.). Цвета выпадающего списка управляются CSS custom properties `--phones-dropdown-bg` и `--phones-dropdown-color`.

## 4. Соцсети (Social)

В настройках темы можно задать до 10 ссылок на соцсети. Для каждой ссылки задаётся URL и иконка (изображение). Шорткод выводит их списком в один ряд — кликабельные иконки, открывающиеся в новом окне браузера.

**Где настраивается:** Внешний вид → Настроить → **Social**.

Для каждого из 10 слотов:

| Поле | Описание |
|------|----------|
| **Social link 1 … 10 (URL)** | URL страницы (например, `https://facebook.com/...`). |
| **Social link N — icon (image)** | Иконка для этой ссылки. Рекомендуется квадратное изображение одного размера для всех. |

Выводятся только слоты с заполненным URL. Ссылки открываются в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`).

### Шорткод [social]

Вывод всех заполненных соцссылок в один ряд (иконки, при клике — переход по ссылке в новом окне).

| Атрибут | Описание |
|--------|----------|
| **class** | Дополнительные CSS-классы для обёртки списка. |

**Примеры:**

```
[social]
[social class="footer-social"]
```

Стили задаются в **assets/scss/_social.scss** (классы `.social-links`, `.social-links__item`, `.social-links__link`, `.social-links__icon`). Если иконка не задана, выводится плейсхолдер «Link».

## 5. Кнопка «Наверх» (Back to Top)

Кнопка возврата к началу страницы. Появляется при прокрутке вниз; по клику страница плавно прокручивается вверх.

**Где настраивается:** Внешний вид → Настроить → **Back to Top Button**.

| Опция | Описание |
|-------|----------|
| **Show button** | Включить или отключить кнопку. |
| **Position** | Положение: Bottom right, Bottom left. |
| **Button style** | Форма: Circle, Square, Rounded. |
| **Size** | Размер: Small, Medium, Large. |
| **Custom arrow (image)** | Своя иконка/стрелка (из медиабиблиотеки). Если не задана, используется встроенная стрелка вверх. |

Поведение задаётся скриптом **assets/js/scroll-to-top.js** (показ после прокрутки ~300px, плавный скролл к верху). Стили — в **assets/scss/_scroll-to-top.scss** (классы `.scroll-to-top`, модификаторы положения, стиля и размера).

На узких экранах (мобильные устройства) колонки отображаются под основным контентом.

## 7.1. Шаблон страницы входа и регистрации (frontend)

Добавлен отдельный шаблон страницы для авторизации и регистрации пользователя с фронтенда:

- **Файл:** `page-auth.php`
- **Template Name:** `Login & Register`
- **Где выбрать:** в редакторе страницы в поле **Шаблон**

Что делает шаблон:

- Выводит две формы на одной странице: **Sign In** и **Create Account**.
- Вход выполняется через `wp_signon()`.
- Регистрация выполняется через `wp_create_user()`.
- Проверяются nonce, обязательные поля, валидность email, совпадение паролей, уникальность username/email.
- Если пользователь уже авторизован, формы не показываются — выводится сообщение о текущем пользователе.
- После успешного входа выполняется редирект на главную страницу.

> Важно: форма регистрации работает только если в WordPress включена опция **«Любой может зарегистрироваться»** (`users_can_register`).

Стили шаблона:

- SCSS: `assets/scss/pages/_auth.scss`
- Подключение: `assets/scss/style.scss` через `@use 'pages/auth';`
- Скомпилированные стили добавлены в `style.css` (блок `.auth-page`, `.auth-card`, `.auth-form`).

## 7.2. Управление колонками для записей и архивов

В теме реализована гибкая настройка отображения боковых колонок для одиночных записей и страниц списков (архивы, блог, поиск).

**Где настраивается:** Внешний вид → Настроить → **Sidebar Settings**.

| Опция | Описание |
|-------|----------|
| **Single Post — Left Sidebar** | Включить левую колонку для одиночных записей. |
| **Single Post — Right Sidebar** | Включить правую колонку для одиночных записей. |
| **Archive — Left Sidebar** | Включить левую колонку для страниц архивов, блога и поиска. |
| **Archive — Right Sidebar** | Включить правую колонку для страниц архивов, блога и поиска. |

### Особенности работы:
1.  **Умное скрытие**: Если колонка включена в настройках, но в соответствующей области виджетов («Sidebar Left» или «Sidebar Right») нет активных виджетов, колонка **не будет выведена**, а контент автоматически займет всё свободное место.
2.  **Макет контента**: На странице одиночной записи изображение (featured image) всегда выводится **под заголовком и мета-данными**, что обеспечивает правильную вертикальную иерархию.
3.  **Адаптивность**: На мобильных устройствах (ширина экрана менее 768px) боковые колонки автоматически переносятся под основной контент.

## 8. Загрузка SVG в медиабиблиотеку

Тема разрешает загрузку файлов **SVG** в медиабиблиотеку (по умолчанию WordPress их блокирует).

- Разрешённые форматы: `.svg`, `.svgz` (MIME: `image/svg+xml`).
- При загрузке выполняется санитизация содержимого SVG: удаляются теги `<script>`, атрибуты-обработчики событий (`onclick`, `onload` и т.п.), ссылки `javascript:` и `data:` со скриптами, чтобы снизить риски при использовании загруженных файлов.

SVG можно использовать как обычные изображения: в логотипах, иконках телефонов и соцсетей, в контенте записей и страниц.

## 9. Стили (Sass) и сборка

Стили темы пишутся в **Sass**. Исходники в папке **assets/scss/**.

- **style.scss** — главный файл, подключает остальные части.
- **Сборка:** в корне темы выполнить `npm run build:styles` (однократная компиляция) или `npm run watch:styles` (автоматическая пересборка при изменении файлов). Результат записывается в корневой **style.css**.

Стили структурированы по папкам:
- **base/** — базовые стили (reset, typography, variables).
- **blocks/** — стили для блоков (header, footer, navigation).
- **elements/** — элементы UI (buttons, forms, tables).
- **pages/** — специфичные стили страниц.
- **shortcodes/** — стили шорткодов.

## 11. WooCommerce

При установленном и активированном плагине **WooCommerce** тема автоматически объявляет поддержку магазина (в том числе галереи товаров: zoom, lightbox, slider). Дополнительной настройки не требуется.

### Шорткод [woo_icons]

Выводит две кликабельные иконки: **кабинет покупателя** и **корзину**. Рядом с корзиной отображается количество товаров и сумма заказа, которые **обновляются без перезагрузки страницы** (реакция на добавление/удаление товаров).

> Шорткод работает **только при установленном WooCommerce**. Без плагина возвращает пустую строку.

**Атрибуты:**

| Атрибут | По умолчанию | Описание |
|---------|-------------|----------|
| `show_label` | `yes` | Показывать текстовую метку с названием и суммой корзины (`yes` / `no`). |
| `cart_label` | `Кошик` | Текст заголовка корзины. |
| `class` | — | Дополнительные CSS-классы для блока-обёртки. |

**Примеры:**

```
[woo_icons]
[woo_icons show_label="no"]
[woo_icons cart_label="Корзина" class="header-woo"]
```

**CSS-классы:**
- `.woo-icons` — обёртка блока.
- `.woo-icons__item--account` — ссылка на кабинет.
- `.woo-icons__item--cart` — ссылка на корзину.
- `.woo-icons__icon-wrap` — круглый контейнер иконки.
- `.woo-icons__badge` — бейдж с количеством товаров (скрыт при нулевом количестве).
- `.woo-icons__label` — текстовый блок с названием и суммой.
- `.woo-icons--icons-only` — модификатор, скрывающий текстовую метку.

Стили задаются в `assets/scss/shortcodes/_woo-icons.scss`.

**Как работает обновление без перезагрузки:**
При добавлении или удалении товара WooCommerce генерирует jQuery-события `added_to_cart`, `removed_from_cart`, `wc_fragments_refreshed`. JavaScript-код в `brainworks.js` перехватывает их и делает AJAX-запрос к серверу, получая актуальные количество и сумму, после чего обновляет все элементы `[data-woo-cart-count]` и `[data-woo-cart-total]` на странице.

## 12. Сетка (Grid System)

В теме реализована отзывчивая сетка на базе Flexbox, аналогичная Bootstrap (v4/v5).

**Файл стилей:** `assets/scss/elements/_grid.scss`.

### Структура
1.  **`.container`** — центрирующий контейнер с фиксированной максимальной шириной на разных экранах.
2.  **`.container-fluid`** — резиновый контейнер на 100% ширины.
3.  **`.row`** — ряд для колонок (flex-контейнер).
4.  **`.col-*`** — колонки.

### Брейкпоинты
- **sm**: ≥ 576px
- **md**: ≥ 768px
- **lg**: ≥ 992px
- **xl**: ≥ 1200px

### Пример использования
```html
<div class="container">
    <div class="row">
        <div class="col-12 col-md-6">
            Половина ширины на среднем экране и шире, полная на мобильном.
        </div>
        <div class="col-12 col-md-6">
            Вторая колонка.
        </div>
    </div>
</div>
```

## 13. Настройка цветов (Color Customizer)

В теме доступна глобальная настройка палитры и привязка цветов к элементам.

**Где настраивается:** Внешний вид → Настроить → **Colors**.

### Возможности
1.  **Palette Colors**: Задайте 7 основных цветов темы (`Color 1` … `Color 7`).
    - *Пример:* Color 1 = Основной бренд, Color 2 = Акцентный, Color 3 = Успех (зеленый) и т.д.
2.  **Element Mapping**: Привяжите логические роли к цветам палитры.
    - **Button 1 Color (Primary)**: Каким цветом красить основные кнопки.
    - **Button 2 Color (Secondary)**: Каким цветом красить вторичные кнопки.

Система автоматически генерирует CSS-переменные (`:root`), которые можно использовать в своем коде:
- `--theme-color-1` … `--theme-color-7`
- `--btn-primary-bg`
- `--btn-secondary-bg`

## 14. Кнопки (Buttons)

Тема предоставляет готовые классы для стилизации кнопок, поддерживающие настройку через Customizer.

**Файл стилей:** `assets/scss/elements/_buttons.scss`.

### Базовые классы
- **`.btn`** — базовый класс кнопки.
- **`.btn-primary`** — основная кнопка (заливка цветом Button 1).
- **`.btn-secondary`** — вторичная кнопка (заливка цветом Button 2).
- **`.btn-outline-primary`** — кнопка с обводкой (цвет Button 1).
- **`.btn-outline-secondary`** — кнопка с обводкой (цвет Button 2).

### Размеры
- **`.btn-sm`** — маленькая кнопка.
- **`.btn-lg`** — большая кнопка.

### Эффекты
- **`.btn-shine`** — добавляет эффект блика (shine) при наведении.

### Анимированная кнопка `.shiny-cta`

Отдельный компонент для акцентных CTA-кнопок с эффектом сияния и анимацией при наведении.

**Файл стилей:** `assets/scss/elements/_shiny-cta.scss`.

Используется как тег `<button>` или `<a>` с классом `.shiny-cta`. **Обязательно** обернуть текст в `<span>`:

```html
<a href="/" class="shiny-cta"><span>Перейти на Главную</span></a>
<button class="shiny-cta"><span>Получить доступ</span></button>
```

Цвета настраиваются через CSS custom properties на элементе:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `--shiny-cta-bg` | `#000` | Фон кнопки |
| `--shiny-cta-fg` | `#fff` | Цвет текста |
| `--shiny-cta-highlight` | `$themeColor1` | Цвет основного свечения |
| `--shiny-cta-highlight-subtle` | `$themeColor1-dark` | Цвет свечения при наведении |

### Пример
```html
<a href="#" class="btn btn-primary btn-lg btn-shine">Купить сейчас</a>
<button class="btn btn-outline-secondary">Подробнее</button>
```

## 16. Настройка меню сайдбара (Sidebar Menu)

Для виджета меню, расположенного в сайдбаре (`.bw-theme-menu`), доступны отдельные настройки цветов, чтобы визуально выделить его среди остального контента.

## 18. Сортировка секций Customizer (для разработчиков)

В теме предусмотрен фильтр `brainworks_customizer_section_priority`, который позволяет разработчикам изменять порядок (приоритет) кастомных секций в Настройщике без редактирования ядра темы.

**Пример использования (в functions.php дочерней темы):**

```php
add_filter('brainworks_customizer_section_priority', function($priority, $section_id) {
    // Переместить секцию Phones (по умолчанию 30) на самый верх
    if ($section_id === 'brainworks_phones') {
        return 5;
    }
    // Переместить секцию Social (по умолчанию 35) в конец
    if ($section_id === 'brainworks_social') {
        return 300;
    }
    return $priority;
}, 10, 2);
```

**ID секций:**
- `theme_colors_section` (Colors)
- `brainworks_mobile_menu_section` (Mobile Menu)
- `brainworks_phones` (Phones)
- `brainworks_social` (Social)
- `brainworks_scroll_to_top` (Back to Top Button)
- `brainworks_scripts` (Third-party Codes)
- `brainworks_login` (Login Page)
- `brainworks_messengers` (Messengers)
- `brainworks_sidebar` (Sidebar)
- `brainworks_fonts` (Fonts)
- `brainworks_sticky_header` (Sticky Header)

## 20. Шорткод [showhide]

Шорткод для скрытия длинного текста с кнопкой «Показать/Скрыть». Текст остается в HTML-коде (индексируется поисковиками), но визуально ограничивается по высоте с эффектом плавного затухания.

### Шорткод
```
[showhide]
Ваш длинный текст здесь...
[/showhide]
```

### Атрибуты
| Атрибут | По умолчанию | Описание |
|---------|-------------|----------|
| **`more_text`** | `Показати` | Текст на кнопке для раскрытия блока. |
| **`less_text`** | `Приховати` | Текст на кнопке для сворачивания блока. |
| **`height`** | `120` | Высота блока в пикселях в свернутом состоянии. |

### Примеры
```
[showhide more_text="Розгорнути" less_text="Згорнути" height="150"]
Текст, который будет частично скрыт...
[/showhide]
```

### Особенности реализации
- **Анимация**: Раскрытие происходит плавно с использованием CSS Transitions.
- **Fade-эффект**: Внизу свернутого блока отображается градиент, плавно уводящий текст в фоновый цвет.
- **Авто-скрытие**: Если текст внутри шорткода короче заданной высоты `height`, кнопка не отображается, и текст выводится полностью без эффектов.

Стили находятся в `assets/scss/shortcodes/_showhide.scss`. Логика анимации — в `assets/js/brainworks.js`.
