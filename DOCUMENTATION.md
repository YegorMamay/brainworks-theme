│   ├── extras.php              # Дополнительные хуки (admin bar, redirect…)

│   └── widget-custom-class.php # Кастомный CSS-класс для виджетов
├── assets/
│   ├── scss/                   # Исходники стилей (компилируются в style.css)
│   └── js/                     # JavaScript-файлы
│       ├── brainworks.js       # Основной JS (мобильное меню, дропдауны…)
│       ├── scroll-to-top.js    # Кнопка «Наверх»
│       ├── woocommerce-quantity.js

## 2. Настройки темы — Кастомайзер

Все настройки доступны в разделе **Внешний вид → Настроить**.

### 2.1 Свойства сайта

Здесь настраиваются основные элементы идентичности сайта:
* **Основной логотип** — выбор изображения логотипа из медиабиблиотеки.
* **Второй логотип** — дополнительный (альтернативный) логотип, например, для использования в подвале (футере) или для тёмного оформления.

### 2.2 Цвета

Для оформления сайта настраивается **цветовая палитра из 7 основных цветов** (Цвет 1–7). Также задаются цвета фона:
* **Фон страниц** — основной цвет фона для всех страниц сайта.
* **Фон главной страницы** — индивидуальный цвет фона для главной страницы.

**Привязка элементов к палитре** — вместо произвольного цвета для конкретных элементов выбирается один из 7 цветов палитры. Это позволяет легко изменить всю цветовую схему сайта, поменяв только базовые 7 цветов:

| Элемент | CSS-переменная |
|---|---|
| Кнопка Primary | `--btn-primary-bg` |
| Кнопка Secondary | `--btn-secondary-bg` |
| Кнопка Accent | `--btn-accent-bg` |
| WooCommerce | `--woo-color` |
| Фон главного меню | `--main-menu-bg` |
| Цвет текста меню | `--main-menu-text` |
| Акцент меню | `--min-menu-accent` |
| Hover фон меню | `--main-menu-hover-bg` |
| Hover текст меню | `--main-menu-hover-text` |
| Фон подменю | `--sub-menu-bg` |
| Фон виджет-меню сайдбара | `.bw-theme-menu` |
| Текст виджет-меню | `.bw-theme-menu ul li a` |
| Бордер/акцент виджет-меню | `.bw-theme-menu` borders |

> **Как работает система цветов:** Сначала настраивается палитра из 7 цветов, затем в параметрах элементов выбирается один из этих цветов. Таким образом, при изменении цвета в палитре он обновится у всех привязанных к нему элементов.

### 2.3 Мобильное меню

Настройки внешнего вида и расположения меню на мобильных устройствах:
* **Позиция** — с какой стороны экрана выезжает меню (слева или справа).
* **Цвета** — индивидуальная настройка цветов для фона меню, текста, обычных и активных ссылок, эффекта при наведении (hover), а также кнопки закрытия и линий-разделителей.

### 2.4 Телефоны

В теме можно добавить до **6 телефонных номеров** для шапки или других областей сайта. Для каждого номера настраивается:
* **Номер** — отображаемый текст телефона (поддерживает HTML-теги, например `<b>` для выделения).
* **Описание** — текстовая подпись (например, «Отдел продаж» или имя сотрудника).
* **CSS-класс** — дополнительный класс стиля для ссылки телефона.
* **Иконка** — выбор изображения-иконки (например, логотип мобильного оператора).

### 2.5 Социальные сети

Настройка до **10 ссылок на профили в социальных сетях**. Для каждого профиля задаётся:
* **URL** — ссылка на вашу страницу/группу.
* **Иконка** — изображение-иконка соцсети из медиабиблиотеки.

### 2.6 Мессенджеры

Раздел для настройки ссылок на популярные мессенджеры (WhatsApp, Telegram, Viber, Skype, Facebook Messenger). Для каждого мессенджера указывается:
* **Ссылка / номер** — имя пользователя, номер телефона или адрес.
* **Иконка** — изображение-иконка мессенджера.

Тема автоматически преобразует введённые контакты в кликабельные ссылки быстрого перехода (например, преобразует телефон для WhatsApp в ссылку вида `https://wa.me/...`).

### 2.7 Кнопка «Наверх»

Управление кнопкой быстрой прокрутки страницы наверх:
* **Показ кнопки** — включение или отключение отображения.
* **Положение** — слева или справа внизу экрана.
* **Форма** — круглая, квадратная или с закруглёнными углами.
* **Размер** — маленькая, средняя или большая.
* **Иконка** — стандартная или собственное изображение.
* **Оформление** — цвет фона и цвет самой иконки.

### 2.8 Шрифты Google Fonts

Выбор шрифтов из библиотеки Google Fonts (по умолчанию используется шрифт *Roboto*):
* **Шрифт заголовков** — применяется ко всем заголовкам (H1–H6).
* **Шрифт основного текста** — применяется к тексту страниц, спискам, ссылкам и другим текстовым элементам.

Доступно около 30 популярных шрифтов.

### 2.9 Липкий хедер

* **Включить липкий хедер** — при включении шапка сайта фиксируется вверху экрана и остаётся видимой при прокрутке страницы вниз.

### 2.10 Сайдбар

Настройки отображения и поведения боковых колонок (сайдбаров):
* **Прилипающий сайдбар** — включает фиксацию боковой панели при прокрутке страницы.
* **Отображение на страницах записей** — включение/отключение левого или правого сайдбара на страницах отдельных статей.
* **Отображение в архивах** — включение/отключение левого или правого сайдбара в каталогах, поиске, блоге и архивах.
* **Адаптивные отступы** — настройка боковых отступов (в пикселях) для разных разрешений экранов (компьютеры, ноутбуки, планшеты, телефоны).
* **Параметры фиксации** — настройка высоты прокрутки, после которой сайдбар фиксируется, и отступа от верхнего края экрана.

### 2.11 Сторонние коды/скрипты

Возможность вставки до **6 произвольных блоков кода** (например, счётчики Яндекс.Метрики, Google Analytics, пиксели соцсетей и онлайн-чаты):
* **Место вставки** — выбор расположения кода на странице (в секцию `<head>`, в начало `<body>` или в подвал перед закрывающим тегом `</body>`).
* **Код** — текстовое поле для вставки скриптов или стилей.

### 2.12 Страница входа

Брендирование стандартной страницы входа WordPress (`/wp-login.php`):
* **Логотип** — собственное изображение логотипа вместо стандартного значка WordPress.
* **Фоновое изображение** — выбор фоновой картинки для страницы входа.
* **Настройки фона** — управление повторением, размером (заполнение, масштабирование), позиционированием и поведением фона при прокрутке.

### 2.13 WooCommerce Icons

*Этот раздел отображается только при активном плагине WooCommerce.* Настройка иконок личного кабинета и корзины в шапке сайта:
* **Иконка «Кабинет» и «Корзина»** — загрузка собственных изображений (рекомендуется SVG или PNG на прозрачном фоне).
* **Размер** — настройка размера иконок в пикселях.
* **Бордер** — включение, толщина и цвет рамки вокруг иконок.

## 3. Шорткоды

### `[phones]`

Выводит список телефонов из настроек темы.

**Атрибуты:**

| Атрибут | По умолчанию | Описание |
|---|---|---|
| `format` | `list` | `list` — `<ul>`, `column` — `<div>`, `dropdown` — выпадающий список |
| `class` | `""` | Дополнительный CSS-класс обёртки |
| `dropdown_bg` | `""` | Цвет фона выпадающего списка (CSS var `--phones-dropdown-bg`) |
| `dropdown_color` | `""` | Цвет текста выпадающего (CSS var `--phones-dropdown-color`) |

**Примеры:**
```
[phones]
[phones format="column"]
[phones format="dropdown" dropdown_bg="#1a1a1a" dropdown_color="#ffffff"]
[phones format="list" class="header-phones"]
```

**HTML-классы:**
- `.phones` — обёртка
- `.phones--list` / `.phones--column` / `.phones--dropdown` — модификатор формата
- `.phones__item` — элемент списка
- `.phones__link` — ссылка `tel:`
- `.phones__number` — сам номер
- `.phones__desc` — подпись
- `.phones__icon-wrap` / `.phones__icon` — иконка
- `.phones__toggle` — кнопка дропдауна
- `.phones__dropdown-list` — список остальных номеров
- `.is-open` — добавляется при открытом дропдауне

### `[woo_icons]`

Иконки «Кабинет» и «Корзина» WooCommerce с мини-корзиной (popup).

> Работает только при активном WooCommerce.

**Атрибуты:**

| Атрибут | По умолчанию | Описание |
|---|---|---|
| `class` | `""` | Дополнительный CSS-класс обёртки |
| `show_label` | `yes` | `yes` / `no` — показывать ли текстовую метку и сумму рядом с корзиной |
| `cart_label` | `Кошик` | Текст метки корзины |

**Примеры:**
```
[woo_icons]
[woo_icons show_label="no"]
[woo_icons cart_label="Корзина" show_label="yes"]
[woo_icons class="header-woo"]
```

**Особенности:**
- Иконки по умолчанию — встроенные SVG. Кастомные задаются в кастомайзере (раздел «WooCommerce Icons»).
- Бейдж с количеством товаров обновляется через WooCommerce AJAX-фрагменты (`data-woo-cart-count`).
- Сумма корзины обновляется через фрагменты (`data-woo-cart-total`).
- Мини-корзина (popup) открывается по клику/hover на иконке корзины.

**HTML-классы:** `.woo-icons`, `.woo-icons--icons-only` (когда `show_label="no"`), `.woo-icons__item--account`, `.woo-icons__item--cart`, `.woo-icons__badge`, `.woo-icons__cart-popup`

---

### `[showhide]`

Блок с контентом, скрытым за кнопкой «Показать/Скрыть» (expand/collapse).

**Атрибуты:**

| Атрибут | По умолчанию | Описание |
|---|---|---|
| `more_text` | `Показати` | Текст кнопки в свёрнутом состоянии |
| `less_text` | `Приховати` | Текст кнопки в раскрытом состоянии |
| `height` | `120` | Видимая высота в px до кнопки |

**Пример:**
```
[showhide more_text="Читати далі" less_text="Згорнути" height="200"]
Длинный текст...
[/showhide]
```

**HTML-классы:** `.show-hide-block`, `.show-hide-content`, `.show-hide-button-wrap`, `.show-hide-button`

> Высота задаётся через CSS-переменную `--show-hide-height` на обёртке.

## 6. Вспомогательные функции (helpers.php)

### `brainworks_get_phones_data() : array`

Возвращает массив данных всех заполненных телефонов.

```php
$phones = brainworks_get_phones_data();
// Каждый элемент:
// [
//   'number'  => '+38 (063) 20-37-130',  // как введён (может содержать HTML)
//   'tel'     => '+380632037130',          // для href="tel:"
//   'desc'    => 'Менеджер',
//   'class'   => 'my-class',
//   'icon_id' => 42,                       // ID вложения
// ]
```

### `brainworks_phone_to_tel(string $display_number) : string`

Преобразует отображаемый номер (`+38 (063) 20-37-130`) в формат для `tel:` (`+380632037130`).

```php
$tel = brainworks_phone_to_tel('+38 (063) 20-37-130'); // → '+380632037130'
```

### `brainworks_get_social_data() : array`

Возвращает массив заполненных соцсетей:

```php
$items = brainworks_get_social_data();
// [['url' => 'https://...', 'icon_id' => 5], ...]
```

### `brainworks_get_messengers_data() : array`

Возвращает массив мессенджеров:

```php
$items = brainworks_get_messengers_data();
// [['url' => '+380631234567', 'type' => 'telegram', 'icon_id' => 10], ...]
```

### `brainworks_get_logo_html(string $which, array $args) : string`

Возвращает HTML логотипа.

```php
// $which: 'main' или 'second'
// $args: ['link' => true, 'size' => 'medium', 'class' => '']
echo brainworks_get_logo_html('main', ['link' => false, 'size' => 'full']);
```

### `brainworks_get_related_posts_html() : string`

Возвращает HTML блока «Похожие записи» для `single.php`. Выбирает 3 поста:
- сначала по тегам текущей записи,
- если тегов нет — по категориям.

```php
echo brainworks_get_related_posts_html();
```

### `brainworks_has_left_sidebar() : bool` / `brainworks_has_right_sidebar() : bool`

Проверяет, нужно ли показывать соответствующий сайдбар.

```php
if (brainworks_has_left_sidebar()) {
    get_sidebar('left');
}
```

### `brainworks_get_layout_class() : string`

Возвращает CSS-класс лейаута для `.site-content`.

```php
<div class="site-content <?php echo brainworks_get_layout_class(); ?>">
```

## 7. Хлебные крошки

Функция `breadcrumbs()` выводит навигационные хлебные крошки с Schema.org разметкой (`BreadcrumbList`).

```php
<?php breadcrumbs(); ?>
```

**Особенности:**
- Не выводятся на главной странице.
- Поддерживают вложенные категории (выводят всю цепочку родителей).
- Поддерживают Custom Post Types (CPT).
- Поддерживают WooCommerce (`product_cat`).
- Разметка `itemscope itemtype="https://schema.org/BreadcrumbList"` на каждом элементе.

## 8. SEO

Функционал в `inc/seo.php` активен **только если Yoast SEO не установлен** (проверка `WPSEO_VERSION`).

**Что генерируется:**
- `<meta name="description">` — из excerpt или описания сайта
- OpenGraph теги: `og:title`, `og:description`, `og:url`, `og:image`, `og:type`
- Twitter Card: `twitter:card`, `twitter:title`, `twitter:image`

**Изображение для соцсетей:**
- Для singular: featured image поста
- Для таксономий (категория, тег, taxonomy): поле `brainworks_social_image_id` из meta записи
- Fallback: `/assets/img/default-og-image.jpg`

**Поле «Social Image» для таксономий** добавляется через `inc/admin-term-image.php` — позволяет загрузить OG-изображение для категории/тега прямо в форме редактирования таксономии.

## 9. WooCommerce

### Поддержка темы

- `woocommerce` — базовая поддержка
- `wc-product-gallery-zoom` — зум при наведении
- `wc-product-gallery-lightbox` — лайтбокс в галерее
- `wc-product-gallery-slider` — слайдер в галерее
- AJAX добавление в корзину на архивах (автоматически включается при активации WooCommerce)

### Shop Toolbar

На страницах магазина, категорий и тегов автоматически добавляется `.bw-shop-toolbar` — flex-обёртка вокруг стандартных элементов WooCommerce:
- Счётчик результатов (`result-count`, priority 20)
- Сортировка (`catalog-ordering`, priority 30)
- Переключатель вида (grid/list, priority 35)

### View Switcher (Grid / List)

Функция `brainworks_view_switcher()` добавляет кнопки переключения вида товаров.

**HTML-классы:** `.bw-view-switcher`, `.bw-view-switcher__btn--grid`, `.bw-view-switcher__btn--list`, `.is-active`

Активный вид сохраняется в `localStorage` и применяется при загрузке страницы.

### GIF-анимации

Фильтр `image_downsize` настроен так, что GIF-изображения всегда отдаются в полном размере (без ресайза), сохраняя анимацию.

### AJAX-корзина для `[woo_icons]`

- `wp_ajax_woo_icons_cart` / `wp_ajax_nopriv_woo_icons_cart` — возвращают `count` и `total` корзины.
- Срабатывает при добавлении товара в корзину через WooCommerce-фрагменты.
- Nonce: `woo_icons_cart`

### Шаблоны WooCommerce

Переопределённые шаблоны находятся в папке `woocommerce/`. Структура должна повторять структуру `woocommerce/templates/` в плагине.

## 10. SVG-поддержка

Тема разрешает загрузку `.svg` / `.svgz` файлов через медиабиблиотеку **только для администраторов**.

При загрузке автоматически происходит санитизация SVG:
- Удаляются теги `<script>`
- Удаляются `on*`-обработчики событий
- Удаляются `javascript:` в href/style
- Удаляются `data:*script` паттерны

### Подключаемые файлы

| Handle | Файл | Условие |
|---|---|---|
| `brainworks-style` | `style.css` | Всегда |

Все ассеты используют `filemtime()` вместо версии темы — кеш сбрасывается автоматически при изменении файла.

### CSS компилируется из SCSS

`style.css` компилируется из `assets/scss/`. При работе с темой редактируй SCSS-файлы, а не `style.css` напрямую.

Устанавливаются динамически через `brainworks_render_theme_css_vars()` в `<head>`:

```css
:root {
  /* Палитра */
  --theme-color-1: #007bff;
  --theme-color-2: #333333;
  /* ... до --theme-color-7 */

  /* Кнопки */
  --btn-primary-bg: var(--theme-color-1);
  --btn-secondary-bg: var(--theme-color-2);
  --btn-accent-bg: var(--theme-color-3);

  /* Меню */
  --main-menu-bg: var(--theme-color-N);
  --main-menu-text: var(--theme-color-N);
  --main-menu-hover-bg: var(--theme-color-N);
  --main-menu-hover-text: var(--theme-color-N);
  --sub-menu-bg: var(--theme-color-N);

  /* Мобильное меню */
  --mobile-menu-bg: ...;
  --mobile-menu-text: ...;
  --mobile-menu-link: ...;
  --mobile-menu-link-hover: ...;
  --mobile-menu-close: ...;
  --mobile-menu-separator: ...;

  /* Сайдбар */
  --sidebar-sticky: sticky | static;
  --sidebar-scroll-trigger: 0;          /* px — глубина скролла */
  --sidebar-sticky-offset-delta: 0px;
  --sidebar-offset-lg: 20px;
  --sidebar-offset-md: 20px;
  --sidebar-offset-sm: 20px;
  --sidebar-offset-xs: 20px;
}
```

**Переменные для `[phones format="dropdown"]`** — задаются inline на элементе:
```css
--phones-dropdown-bg: #1a1a1a;
--phones-dropdown-color: #ffffff;
```

## 13. Особенности и тонкости

### Сброс настроек кастомайзера

В каждом разделе кастомайзера есть кнопка «Reset» — сбрасывает только настройки текущего раздела через AJAX (`wp_ajax_brainworks_reset_customizer`).

### Admin Bar

Для не-администраторов и пользователей без права `edit_posts` admin bar скрыт.

### Удалённые стили Gutenberg

Тема удаляет стили блоков Gutenberg (`wp-block-library`, `wp-block-library-theme`) и WooCommerce-блоков (`wc-block-style`) для оптимизации загрузки.

### Excerpt для страниц

Тема добавляет поддержку поля «Цитата» (excerpt) для страниц (post type `page`) — используется для SEO description.

### HTML в описаниях таксономий

Фильтры `wp_filter_kses` и `wp_kses_data` для описаний термов удалены — в описаниях категорий и тегов можно использовать HTML.

### Планировщик удаления

Автоматическое удаление записей из корзины по расписанию (`wp_scheduled_delete`) отключено.

### Yoast SEO — автоматические редиректы

При переименовании slug Yoast не будет создавать автоматический редирект (`wpseo_premium_post_redirect_slug_change` → `true`).

### Google Fonts: запрашиваемые варианты

Все шрифты запрашиваются с весами `400`, `700` и курсивами `400i`, `700i`.

### Редактор Gutenberg

Тема подключает `style.css` к редактору (`add_editor_style`), поддерживает `align-wide`, `custom-line-height`, `custom-units`.

## Быстрый старт для нового разработчика

1. **Логотип** → Кастомайзер → Свойства сайта → Main Logo
2. **Цвета** → Кастомайзер → Colors → задай 7 цветов палитры, привяжи элементы
3. **Шрифты** → Кастомайзер → Fonts
4. **Телефоны** → Кастомайзер → Phones → Phone 1…6
5. **Соцсети** → Кастомайзер → Social
6. **Мессенджеры** → Кастомайзер → Messengers
7. **Меню** → Внешний вид → Меню → назначь в позиции `main-menu`, `mobile-menu`
8. **Виджеты** → Внешний вид → Виджеты → заполни `Footer`, `Sidebar Left/Right`
9. **Аналитика** → Кастомайзер → Third-party Codes → вставь скрипты в нужное место
10. **WooCommerce иконки** → Кастомайзер → WooCommerce Icons → загрузи SVG-иконки

**Вставка элементов в шаблон:**
```php
<?php echo do_shortcode('[main_logo]'); ?>
<?php echo do_shortcode('[phones format="dropdown"]'); ?>
<?php echo do_shortcode('[social]'); ?>
<?php echo do_shortcode('[messengers]'); ?>
<?php echo do_shortcode('[woo_icons show_label="yes" cart_label="Корзина"]'); ?>
<?php breadcrumbs(); ?>
<?php echo brainworks_get_related_posts_html(); ?>
```
